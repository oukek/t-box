# OS 桌面与应用安装边界

主导航为 AI / OS，原 `#/` 和 `#/applications` 路径保留，仅这两个主页面显示底部导航。OS 的「设置」仍使用 `profile` 应用 ID，旧 `#/profile` 深链仍有效，账号子页面返回设置。余额、费用说明、资源、任务记录集中到 AI 页顶部「AI 中心」侧栏；新页面使用 `#/ai/wallet`、`#/ai/recharge`、`#/ai/pricing`、`#/ai/resources`，原 `#/profile/*` 链接和支付回跳兼容。充值返回余额，余额/资源返回 AI；从余额进入费用说明则返回余额。应用从 OS 打开返回 OS，从 AI 打开仍可返回 AI。

设置提供图标大小：小、中、大分别为 44、56、68 CSS px，默认中；图标、日历数字和拖动预览同步缩放。手机、平板和 PC 使用相同的图标尺寸，网格按容器宽度自动换行；单元格最小宽度为图标加 8px，列间距为 8–12px，换行后的少量余量均分到所有列，不拉伸图标。保留空列，避免应用少时拉大间距。桌面水平内边距手机为 12px、大屏为 24px。大小按账号保存于当前设备 localStorage，旧 Enter/动效选项不再读取。桌面排序仍由后端分别保存移动端和 PC 布局。电脑端 Enter 发送、Shift + Enter 换行；移动端 Enter 换行，通过发送图标提交。浏览器禁止存储时，图标大小仅在当前会话内生效。

桌面时钟显示时、分、秒，与动态应用图标共用每秒更新的时钟；页面隐藏时暂停，恢复可见时立即同步当前时间。

桌面采用本地山湖暮色壁纸、白色时钟与图标名称、底部半透明 AI / OS 导航；品牌栏不占用顶部空间，应用内部和 AI 页使用各自样式。壁纸文件、响应式裁切方式和生成提示词见 [桌面壁纸](desktop-wallpaper.md)。

## 桌面与 AI 分开注册

- `shared/src/desktop.ts` 提供可信系统应用目录、安装元数据及桌面 DTO。
- `packages/app-shell-sdk/src/contracts.ts` 中 `ClientApplicationModule` 提供页面、导航、安装类型，`ai` 为可选适配器。「设置」没有 `ai`，不会出现在聊天的艾特列表，也不声明工具或资源授权钩子。
- `api/src/applications/registry.ts` 只注册 AI 能力。后端桌面接口从这里推导 `aiAvailable`，不会以图标存在作为模型可调用的证据。
- 页面参数由模块的 `props(params, {openRevision})` 转换；模块按需消费打开次数，宿主不把无用属性强加给所有组件。

现有应用包含系统应用与用户应用；原 shell 模块来自静态可信组装，独立 Web 应用经受限容器运行，不把应用代码导入宿主。后台只能注册受校验的静态构建产物，不能用数据库字段加载任意服务端代码。

新增普通应用需要共享 manifest、前端模块和可信桌面目录；只有需要 AI 调用时才提供后端工具/技能及前端 `ai` 适配器。业务 API 不要求依赖 AI。

## 用户排序

`user_desktop_layouts` 的主键为 `(user_id, device)`，保存 JSON 应用 ID 顺序、版本号与更新时间。账号由 Bearer 登录认证确定，请求不能指定其他用户。移动端采用宽度不超过 700px 的紧凑布局，PC 为更宽的布局；同一账号两套排列独立。

- `GET /api/v1/desktop/:device`（mobile / pc）返回 `DesktopSnapshot`：已安装应用、安装元数据、AI 可用标记、顺序、revision 和 catalogRevision。
- `PUT /api/v1/desktop/:device` 仅接受 `{appIds, revision, catalogRevision}`，要求完整且不重复的已安装 ID 集合。不能用省略 ID 的方式移除系统应用，不能伪造安装类型。
- 保存事务锁定账号与目标布局，比较版本。两个窗口基于同一版本保存不同排列时，后提交者收到 `DESKTOP_LAYOUT_CHANGED`，前端加载服务端排序再提示重新整理。相同目标的重试是幂等的，适用于成功回包丢失。
- 应用目录新增时保留已有相对顺序，将新应用追加；不再安装的应用从排列剔除。catalogRevision 变化拒绝旧目录覆盖。
- 前端连续拖动串行保存并合并待保存排列，网络失败保留待提交顺序、提供重试；切换账号或设备时取消旧请求，不把旧账号结果应用到新桌面。

桌面不显示常驻整理按钮。长按图标 450ms 进入编辑模式，继续移动即可拖动排序；右键也可进入，键盘使用 F2 或 Shift+F10。鼠标、触摸和笔使用同一套 Pointer Events，长按松手不会误打开应用详情；未长按时仍允许正常滚动。点「完成」、桌面空白处或按 Esc 退出。完成按钮仅在编辑时出现且不改变网格位置。编辑模式的方向键与应用信息里的前后移动按钮提供替代操作。排序仅修改入口位置，不影响业务数据或 AI 任务。

## 系统应用与用户应用

`ApplicationInstallation` 独立声明 `kind: system | user`、`uninstallable` 及可选 installationId。记账为可卸载用户应用；计算器、日历、时间、设置、市场为系统应用，可以升级但不能卸载。类型以数据库应用级 registry 为准，版本不能改变卸载规则。

安装、更新、卸载由应用市场的独立接口处理。卸载立即撤销入口、REST、实时连接和 AI 工具调用权限；账本与历史数据保留。排序接口仅处理布局，不承担安装或卸载职责。

部署先运行 `pnpm db:init`。`pnpm test:desktop` 验证真实 MySQL 账号/设备隔离、持久化、并发版本冲突、幂等重试、系统应用保护、AI 独立性与 PUT 预检。

## 应用市场

桌面新增应用市场系统入口。目录来自用户持久化安装状态，记账是当前可卸载的用户应用，其余现有应用为可升级的系统应用。市场管理安装、更新、卸载，卸载墓碑不会因刷新或重启丢失。排序摘要随安装状态改变，详情和实现边界见 [独立应用平台](application-platform.md)。

## 应用类型与版本管理更新

记账为可卸载用户应用；计算器、日历、时间、设置、市场为系统应用，可升级但不可卸载。类型由应用级 registry 确定，与 shell/web 运行方式独立。市场包含全部系统应用的版本入口。后台提交、发布与历史版本切换见 [应用平台](application-platform.md#后台提交发布与更新)。
