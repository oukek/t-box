# T方舟 · iOS 1.0.0 上架资料

## 1. 先发布三个公开页面

运行 GitHub Actions「主界面构建（网页、PWA、Mac）」，在方舟管理后台「应用管理 → 系统发布」确认发布包含本次改动的网页版本。若当前 UI 版本已上线，先在根目录 `release-versions.json` 设置下一个可发布的 UI 版本。iOS 商店版本为 `1.0.0`。用未登录的浏览器分别打开下面三个网址，看见产品介绍、「使用支持」和「隐私政策」正文并能点开联系邮箱，再提交 Apple。只上传 iOS 包不会更新主站。

**描述**（复制下面三段）

T方舟把日常用得到的计算器、单位换算、日历和时钟放在一起。看食谱时换算温度，做预算时算出一串数字，约跨时区电话前看一眼当地时间，打开对应工具就能开始。

计算器支持基础算式和科学运算。单位换算可以按长度、面积、温度等类别选择单位，输入数值后查看换算结果。日历可以按月查看日期；世界时钟可以把常看的城市放在一起，方便比较时间。

计算、单位换算和秒表可以直接使用。需要保存云端倒计时时，登录自己的账号即可。

## 4. 审核信息与提交

- 在「构建版本」选这次上传且处理完成的 1.0.0。审核联系人填写 Apple 能实际联系到的姓名、电话和邮箱，公开支持邮箱为 249900679@qq.com。账号功能需要准备可用的专用审核账号，在 Apple 的登录信息栏填账号和密码，提交前用新设备试登。
- 审核备注可从这段开始，按该构建实际开放的目录、联网服务及权限补充：『打开应用列表，选择计算器或单位换算，输入数值即可体验。日历、时间、单位换算和计算器的基础界面随安装包提供。登录审核账号后可体验账号下的云端功能。在使用需要系统权限的操作时，系统会请求相应授权。』
- 在「App 隐私」按正式构建、服务器及第三方实际行为填写。核对账号标识、昵称及头像、用户提交的文字/照片/文件、共享及交易记录，以及诊断日志，分别确认用途、是否关联用户、是否用于跟踪。区分仅设备端处理的输入与会传到服务器的内容。[Apple 隐私填报说明](https://developer.apple.com/app-store/app-privacy-details/)
- 在「App 信息」按实际功能回答年龄分级，在「定价与销售范围」确认实际价格、地区及相关资质。核实正式版本中所有入口、数据用途和审核说明一致。支持注册的 App 要检查应用内发起删除账号的完整流程；仅提供联系邮箱通常不足以满足此要求。[Apple 账号删除说明](https://developer.apple.com/support/offering-account-deletion-in-your-app/)
- 「版本发布方式」选择「手动发布此版本」，保存并添加以供审核。审核账号密码及私人电话只填在 Apple 后台。
