# 电商助手 1.4.1：采集与项目商品

顶层入口为小助手、个人采集表、项目管理。小助手沿用原稿、创作规则、图片上传和结果弹窗，临时任务仅保存在服务进程内，30 分钟后过期，不写创作记录或商品库；服务重启不恢复临时任务。用户主动保存的创作模板独立持久化，首次读取沿用个人工作区原模板。图片上传及 AI 生成文件仍由已有文件服务管理，不等于无持久化文件。

个人采集表归账号所有。插件登录后选中商品、确认目标账号、点击确认采集；服务端按账号和来源去重，重复确认保留第一次原始快照，既有项目版本不被覆盖。上传按商品逐件确认，失败返回已成功列表，界面保留未成功选项供重试。来源图片和视频仍是外部链接，本次没有转存源站媒体。未安装电商助手也能先采集，安装后以同账号查看。

项目创建时选择国家站点；旧项目继续保留所有工作簿数据，进入商品功能前需要管理员补选站点。项目内已有商品后不能更换站点；不同国家新建项目。原成员邀请、角色、退出功能保留。项目详情有项目商品、计价表两个入口。计价表沿用原组件、公式、Sheet、导入导出和自动保存，只移动入口。

## 商品与定价

从个人采集表认领时，当前项目已认领的条目不可重复选择。数据库唯一索引及项目事务锁保证重复/并发认领只有一件项目商品。同一来源可以认领到不同项目，其他账号不能读取个人采集库；项目成员按原有角色协作项目商品。

每件项目商品初始有一个版本，可人工复制，或使用原 AI 工作台创建优化版本；AI 结果需明确点击创建新版本，不覆盖原版本。列表标记是否修改。每版本最多 1000 个 SKU，编辑列表每页 20 个，可按规格/编码筛选，支持添加、移除、改名及修改自有编码。来源 SKU ID 单独保存。非人民币或未提供的源价格不会冒充人民币成本，需人工确认。

SKU 算价弹窗只读取当前项目 Sheet 元信息和配置，复用 core.calculate 与原物流/汇率数据，不调用 workspace_patch。可选 Sheet、三种计算模式并修改本次成本、国内运费、重量、目标、折扣、费率与汇率。确认回填 SKU 折前售价和币种，保存商品后持久化。本次输入、路线运费规则、费率、计算结果、Sheet 名称和时间作为快照保存；再次改价优先恢复快照，使用最新方案需主动选择。采购成本变更会清空原售价，要求重算。不同币种 Sheet 不允许用于当前项目。

原计价表仍可独立编辑和自动保存。商品编辑使用明确保存与版本修订校验，冲突不会覆盖他人内容。确认回填后取消商品编辑会丢弃未保存的本次改价。

## 数据库与发布

新增扩展 `2026-11-27.shop-tools-catalog`，新增表：

- `shop_tools_collection`：账号采集原始资料。
- `shop_tools_catalog`：项目认领商品，唯一 `(project, source)`。
- `shop_tools_catalog_versions`：版本内容、独立 SKU 和计价快照、修订号。
- `shop_tools_project_sites`：项目国家站点。
- `shop_tools_assistant_settings`：个人创作模板。

所有关联均为普通字段和索引，无新增外键。既有 `shop_tools_products` 工作簿商品行和 `shop_tools_creations` 历史记录保持不变。应用增加 `shop-tools.catalog` 权限。插件调用经过登录认证的 `/api/v1/collector/products`，账号 subject 由服务端推导，不能指定其他账号归属。

发布顺序：

1. 部署同提交 API（PM2，启动服务），现有初始化流程应用建表扩展。
2. 执行「子应用发布（OSS）」选择电商助手，版本 `1.4.1`，在后台审核上架；客户端更新应用以获取新增权限。
3. 分发采集插件 `0.4.0`，重新加载插件并刷新店小秘页面。
4. 真实账号验证确认采集、跨账号隔离、项目认领、AI 文案/图片生成、SKU 改价与原计价表独立保存。

本次无需改 Mac 核心或主站 UI 版本；后台新增版本安装包入口需发布后台界面，未执行线上发布。局部类型检查、构建、计算单测、数据库隔离库集成测试及模拟客户端的浏览器交互检查不代替真实插件/模型/生产发布验收。

## 插件下载发布

GitHub Actions 继续使用「子应用发布（OSS）」并选择电商助手，无需单独的 Chrome 商店工作流。电商助手 Web 构建先重新构建采集插件、打包 ZIP，再将 ZIP、版本/校验信息和独立安装说明页放入同一静态产物。插件构建失败会中止应用构建，不会沿用旧包。OSS 的产物摘要覆盖这些文件，回退应用版本时下载的插件也随版本回退。

后台电商助手 1.4.1 起的版本行提供「采集插件下载与安装」，可在发布前下载检查；按原流程审核发布应用。前端电商助手顶栏提供「下载采集插件」，展示当前应用构建对应插件版本和安装步骤。修改插件时需要提升插件版本，并提升电商助手版本重新提交；已安装用户需更新电商助手才能看到新下载包。ZIP 属于应用公共静态资源，不是私有附件。

Chrome 普通 Windows/macOS 用户需要解压、开启开发者模式、加载含 manifest.json 的目录。安装目录不能删除，更新需覆盖原目录并手动重新加载，没有 Chrome 商店自动更新。CRX 不是普通设备的一键安装替代方案。企业受管安装不在本次范围。
