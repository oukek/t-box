## 首页与安装

- 手机首页占满可见高度，预留系统安全区。根据可用高度和图标大小安排每页容量，超出的图标左右翻页，也提供可点的翻页控件。应用详情、表单、列表仍能正常滚动。
- 网页首页右上角常驻「安装方舟」。桌面浏览器首选「添加到电脑」，手机与 iPad 首选「添加到主屏幕」，三端都能看到 Mac 下载选项。
- 正式实现按浏览器能力决定操作。支持安装提示时调起系统安装；Safari 等提供相应菜单步骤；内置浏览器先指引在系统浏览器打开。原生 Mac 和独立运行的 PWA 收起本端安装提示。手机上的 Mac 安装包明确标注用途。
- 浏览器能可靠识别 Mac 架构时标注推荐项，始终保留手动选择。截图以 iPhone / iPad Safari 和桌面浏览器为示例。

## 子应用布局

- 方舟统一提供返回入口、内容起始线和窗口边距。子应用根据自身可见宽度切换布局，包括 iPad 分屏，不按设备名称写死。
- 待办、记账等列表页面在宽屏使用导航、主列表及有实际内容的辅助栏，窄屏改成页内导航和单栏。任务较少时保留自然的纵向空白。
- 计价、明细等宽表页把导航之外的宽度交给表格；列超出时只横向滚动表格。计算器等工具和短表单保留适合操作的内容宽度。日历按容器宽度分配日期列。
- 本轮为视觉确认稿。上线时保留已有壁纸设置、桌面图标整理、账号和通知入口，以及各子应用现有操作。
