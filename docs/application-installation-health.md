# 应用安装、记账独立化与故障隔离

记账从 1.1.0 起使用独立 Vite/Vue Web 产物（开发端口 5177），宿主只组合 `apps/ledger/shell` 的范围声明与 AI 交互适配器。账本、记录、分类、统计、共享、附件及领域 API 均留在 ledger 应用自己的包内。`pnpm apps:workflow` 会把 ledger 加入手动 Actions 的选项；后续版本仍是上传 OSS、提交入库、后台手动发布。

## 默认安装和失败处理

- 计算器、日历、时间、设置、市场属于系统应用，自动安装，前后端都禁止卸载。记账为默认预装、可卸载的用户应用；卸载墓碑保留，访问桌面不会自动装回，更不会删除账本。
- `active` 表示后端安装完成，独立页面仍需加载资源和完成 SDK 握手。桌面保留安装中/失败的系统应用图标，显示状态，信息面板和应用异常页可重试。单个应用不可用不禁止使用 AI、OS 或其他应用。
- 远程默认安装在后台处理，不阻塞整个默认安装流程。未知结果使用原操作 ID 查询与恢复，避免重新执行不确定的写入。后台恢复采用递增退避，最长 10 分钟；前端有安装状态时定期刷新。
- 明确拒绝的系统安装由后台恢复任务或后续访问按退避自动重试，最多累计 5 次，之后由用户手动重试。用户应用不在后台自动反复安装。重试必须通过后端用户身份与安装策略校验。
- 更新失败保持旧版本 `active`；新的版本只有安装钩子确认完成后才替换。卸载只撤销访问，账本/记录不删除。
- 独立应用部署文件缺失时记录该应用的部署问题，不在模块加载时抛出异常阻止整个 API 启动。生产环境打开独立应用时校验产物完整性，失败在该应用页面提示。MySQL 等平台基础依赖错误仍作为服务错误处理。

## 首次从旧内置记账迁移

先执行 `pnpm db:init`（dist 部署使用 `node dist/init-db.js`），新增安装错误和重试字段。先构建、部署独立记账资源，再部署 API 和宿主，或使用已包含 ledger 初始包的 Docker/PM2 构建链路。准备脚本逐个处理初始包，保留已有 deployment.local.json 和用户资源。

生产配置 `apps/ledger/deployment.local.json` 与计算器相同：

```json
{ "origin": "https://apps.example.com", "artifact": "完整的64位SHA256摘要" }
```

API 组合代码显式声明 `shellMigrations: ['ledger']`。首次检测到线上记账仍为旧 shell 时，才登记并启用随可信部署提供的 Web 版本，旧发布定义保持不可变并保留审计。随后按用户迁移旧的有效安装，增加 generation，使旧运行时失效；卸载记录不激活，正在处理的操作不强行覆盖，完成后再迁移。

这是本次运行架构迁移的一次性行为，与普通 CI 发布分开。线上已是 Web 版本时，API 重启不会替换管理员已发布的版本，也不会自动升级所有用户。迁移不改动账本、成员、密码授权、账单、附件和桌面排序。

## SDK 与 AI 交互

独立记账使用通用 `app-sdk` / `app-web-sdk`，不导入宿主状态或登录 token。JSON REST 通过受限 `api.request` 能力，由 ledger/shell 声明 `/ledgers`、`/ledger-invitations` 接口范围。宿主校验路径、方法、权限、运行时 generation 后附加认证；应用不能指定任意 URL、Authorization 或其他自定义头。既有领域 API 再检查用户身份、安装、账本成员、账本解锁权限和写入幂等。

普通桥接请求最多 64 KB，附件接口的 JSON 桥接请求单独限制为 15 MiB，业务层继续限制单文件 10 MiB。文件仍通过已有受授权的附件接口上传、预览及下载。框架复用导航、订阅与资源绑定能力，不在 AI 调度器加入记账业务。

前端提供 `application_authorize` 和 `finance_confirm`。宿主检查安装版本及工具声明后打开独立页面，输入密码和财务确认在该页面完成。密码仅通过授权接口提交，AI 收到授权/拒绝结果；已有 10 分钟服务端授权机制沿用。关闭页面或取消任务会取消交互。应用内部导航使用消息事件更新参数，避免切换账本重载 iframe；过期账户或安装 generation 会关闭通道。

选中账本通过应用范围的资源绑定供 AI 使用。轻量 shell 适配器恢复已选账本或默认账本元信息，首次进入 AI 时也可找到目标账本；账本密码和财务确认 UI 始终在独立页面。邀请链接使用宿主地址，`#/join` 跳转到独立记账；原生环境没有可分享的网页地址时提供可粘贴的邀请口令。

开发运行 `pnpm dev`，或宿主/API 启动后运行 `pnpm dev:apps`。Actions 可选 ledger，Docker 和 PM2 包均包含计算器及记账的初始静态包。日历、时间仍是不可卸载的系统应用，其界面版本暂随宿主构建。
