# 账本、协作与统计

## 领域边界

普通账号与后台管理员分开。普通用户在 `app_users`，管理员在 `admin_users`。账本列表通过 `ledger_members` 关联，加入共享账本后访问同一份数据，不复制账单。往来对象只是账本中的姓名或公司，不等于成员，更不代表对方确认了这笔债务。

账本提供三种模板：日常收支、往来、综合。模板决定可以创建的记录种类；共享、密码和统计是每种账本都具有的能力。币种暂为 CNY，账本统计日历采用 Asia/Shanghai，金额以十进制字符串传输，使用 bigint 分计算及 MySQL DECIMAL 存储。

默认收入、支出分类在创建账本时各复制一份，之后独立管理。分类名在 `(ledger_id,type,label)` 范围唯一；账单的 `(ledger_id,category,type)` 复合外键禁止使用其他账本或其他收支类型的分类。

后端模块分别处理身份（identity）、账本/授权（ledgers）、财务记录（finance）、统计投影（statistics）、REST/实时通知/对话上下文组合（platform）。Vue 的账号、账本选择、记录、往来、统计、设置独立组织；组件映射与纯应用目录分离，导航不反向依赖页面组件。

## 应收、应付与收还款

方向始终以账本为主体，不随查看者改变：应收是别人欠账本，应付是账本欠别人。

| 操作         | 普通收入/支出 | 资金流   | 往来变化       |
| ------------ | ------------- | -------- | -------------- |
| 普通收入     | 收入增加      | 流入增加 | 不变           |
| 普通支出     | 支出增加      | 流出增加 | 不变           |
| 本次借出     | 不计入        | 流出增加 | 应收增加       |
| 本次借入     | 不计入        | 流入增加 | 应付增加       |
| 补录已有往来 | 不计入        | 不产生   | 应收或应付增加 |
| 收款         | 不计入        | 流入增加 | 关联应收减少   |
| 还款         | 不计入        | 流出增加 | 关联应付减少   |

`debt_positions` 保存原金额、已结算、剩余、对象、发生日、到期日和记录方式；`debt_settlements` 保存一次收款或还款；`settlement_allocations` 保存该次款项分配到哪些往来。允许部分结算、同一对象同一方向一次结算最多 20 笔。不能超出任何一笔的剩余金额，也不能跨账本分配或将应收与应付混结。

建立往来和收还款的发生日不能晚于今天；到期日可在未来。收还款日期不得早于关联往来。利息、手续费和核销尚未建模，不能直接当本金冲抵。

撤销收还款用于纠正误记：保留原记录及分配关系，恢复关联余额，在原日期写入反向事件并修正统计。实际退款与误记撤销不是同一业务，需要之后另行建模。普通账单修改和删除保留事件与审计，不物理删除原记录。

## 日、月、季度、年统计

只维护两张日投影：

- `ledger_daily_stats`：每账本每日的普通收入、支出、资金流入/流出、应收/应付净变化、收支笔数。
- `ledger_daily_categories`：每账本每日每分类的金额、收支笔数。

月、季度、年按对应日期范围聚合日投影，不另建四套统计表，也不在每次查询时扫描所有账单和结算分配。完整明细来自 `ledger_events`，它保存各次财务行为的带符号变化。统计页面提供期间选择、分类汇总、趋势以及分页事件明细；点趋势日期可缩小明细范围。

期间普通结余为收入减支出，资金净流入为资金流入减流出，两者不能混用。往来余额分别展示：

- 期初：发生日期早于期间开始的累计变化。
- 期末：发生日期不晚于期间结束的累计变化。
- 当前剩余：截至今天的累计变化，与所选期间无关。

例如 9 月借出 1,000、10 月收回 300：9 月期末应收 1,000，当前剩余应收 700，10 月资金流入 300，普通收入为 0。

统计读取使用 MySQL REPEATABLE READ 事务，结果携带账本 revision。同一次统计中的期间金额、余额、分类和日序列来自一致快照。往来列表分页不影响剩余总额，普通账单分页/搜索不影响统计。

## 写入一致性、幂等与重建

财务写入在账本行 `SELECT ... FOR UPDATE` 的事务中完成：

1. 重新检查登录、成员权限、归档状态和账本解锁。
2. 检查持久化幂等键及参数摘要。
3. 创建/修改业务记录，更新关联往来余额。
4. 写入不可变的财务事件，同步更新日投影与分类投影。
5. 保存操作结果，增加 revision，写审计，提交。

任何一步失败全部回滚。共享成员同时还同一笔钱时，账本行锁串行化操作，后到的请求检查最新剩余金额，不能透支。当前锁粒度适合个人/小规模协作账本，单账本高吞吐时可以进一步细化锁，不能直接移除一致性保护。

写入收支、分类、往来和收还款必须传 `Idempotency-Key`。唯一范围为账本 + 用户 + 请求键；同键同参数返回原结果，同键不同参数返回 409。页面保存账单/往来/收还款在未改变内容的重试中保留键；AI 根据会话请求与工具参数生成稳定键。幂等记录持久化在 MySQL，API 重启不会丢失已经提交的结果。

`POST /ledgers/:id/statistics/rebuild` 允许解锁后的所有者/管理员从 `ledger_events` 重建该账本的投影，保留业务明细。历史账单移日期时，旧日期写负变化，新日期写正变化；历史期间因此按修正后的事实重算。以后若需要财务关账，必须另加期间锁定和跨期调整规则。

Redis 当前只用于已有的连接管理/健康检查，不作为余额真相或必要统计缓存。每账本十年的日投影也只有约 3,650 行，先用带账本/日期索引的聚合即可。将来若查询压力明显增加，可缓存 `ledger_id + period + value + revision` 的统计响应；必须同时包含当前余额所对应的版本及权限/解锁校验，不能直接拿缓存绕过授权。

## 成员、邀请与密码

| 角色     | 权限                                                     |
| -------- | -------------------------------------------------------- |
| 所有者   | 所有行为、改名/归档、账本密码、转让所有权                |
| 管理员   | 记账、修正所有记录、邀请普通成员、管理普通成员、重建统计 |
| 记账成员 | 查看、新增记录、修正自己的账单与收还款                   |
| 只读成员 | 查看记录、统计、成员及审计                               |

只有所有者能任免或邀请管理员。所有者不能直接退出，需要先转让给已有成员。成员退出/移除后，原有记录保留，访问和解锁凭据失效。归档保留查看功能并禁止财务写入。

邀请令牌随机生成，数据库只保存摘要，生成时仅返回一次原令牌；有效期 1–7 天，可加入人数 1–20，可撤销。登录后确认加入，不同成员共享同一本账本。邀请者失去相应权限时，未使用邀请不能继续授予权限。邀请链接使用 URL fragment，令牌不会作为 HTTP 请求 URL 查询参数发送给服务器。

账本密码至少 6 字符，以 scrypt 摘要保存。密码不能代替成员身份；解锁凭据绑定账本、账号会话、密码版本，10 分钟到期，分为只读和读写范围。改密码会撤销所有已有解锁。所有者可以验证账号密码后重置或关闭账本密码，即使账本已锁也可执行。密码只进入专用 REST 表单和校验，不进入模型上下文。此机制是服务端访问保护，不是端到端加密。

普通账号会话为七天有效的随机令牌，数据库保存摘要；客户端保存令牌，REST 通过 Bearer 发送，WebSocket 通过首条认证消息发送，不放进 URL。改账号密码会撤销所有账号会话。公开部署必须使用 HTTPS/WSS；注册、登录和解锁的限流在当前 API 进程内，账号失败锁定持久化，多实例部署应将进程内限流迁移到共享存储。

## 对话工具与实时同步

`session.open` 携带普通账号的 `authToken`，会话绑定用户，恢复时检查该用户及原账本的访问权限。`message.send` 指定 `ledgerId`，服务端生成该次运行的账本上下文，REST 与对话调用同一财务服务。切换账本清除提供给模型的旧工具上下文；模型变更也不会重新注入其他账本的历史消息。

普通记账使用 `categories_list` → `bills_create` → 前端 `app_open`，打开参数由服务器绑定当前账本。`ledger_statistics` 和 `debts_list` 只读取当前账本。`debts_create`、`settlements_create` 的后端执行会先发送 `finance_confirm` 给前端，展示后端校验过的对象、方向、金额、分配和账本，等待当前运行/连接对应的确认回执。拒绝、取消、断线或超时都不能授权新的写入；收到确认后写入事务仍重新检查权限和剩余金额。

`/api/v1/ledgers/ws` 用于账本 revision 通知，客户端先认证，再订阅已解锁账本。提交后发送变更通知，页面从 REST 读取最新数据。通知发送前重新检查账号、成员和解锁；失权/锁定时发送撤销事件并停止订阅。通知不包含财务明细；断线重连后恢复订阅并根据 revision 刷新。当前通知在单进程内，多实例需要共享 Pub/Sub 或 outbox 分发。

对话记录仍保存在进程内存，重启后需要新建对话，但账本、业务记录、投影、审计和已提交的财务幂等结果都在 MySQL。

## 主要接口

统一前缀 `/api/v1`，账本相关接口均需普通账号身份。

| 方法                 | 路径                                              | 用途                               |
| -------------------- | ------------------------------------------------- | ---------------------------------- |
| POST                 | `/auth/register`, `/auth/login`                   | 注册、登录                         |
| GET                  | `/auth/me`                                        | 当前普通用户                       |
| DELETE               | `/auth/session`                                   | 退出当前会话                       |
| PATCH                | `/auth/password`                                  | 改账号密码并撤销所有会话           |
| GET / POST           | `/ledgers`                                        | 我的账本列表、创建                 |
| GET / PATCH          | `/ledgers/:id`                                    | 账本元数据、改名/归档              |
| POST / DELETE        | `/ledgers/:id/unlock`                             | 解锁 / 锁定                        |
| PATCH                | `/ledgers/:id/password`                           | 设置、重置、移除密码               |
| GET / POST           | `/ledgers/:id/invites`                            | 查询邀请 / 生成邀请                |
| DELETE               | `/ledgers/:id/invites/:inviteId`                  | 撤销邀请                           |
| POST                 | `/ledger-invitations/accept`                      | 接受邀请                           |
| GET                  | `/ledgers/:id/members`                            | 成员列表                           |
| PATCH / DELETE       | `/ledgers/:id/members/:userId`                    | 改角色 / 移除 / 自己退出           |
| POST                 | `/ledgers/:id/transfer`                           | 转让所有权                         |
| GET / POST           | `/ledgers/:id/categories`                         | 账本分类 / 新建分类                |
| GET / POST           | `/ledgers/:id/bills`                              | 分页收支明细 / 记账                |
| GET / PATCH / DELETE | `/ledgers/:id/bills/:billId`                      | 查看 / 修改 / 删除                 |
| GET                  | `/ledgers/:id/bills/summary`                      | 兼容记录页的当月普通收支汇总       |
| GET / POST           | `/ledgers/:id/debts`                              | 分页往来列表 / 建立往来            |
| GET / POST           | `/ledgers/:id/settlements`                        | 最近 500 笔收还款 / 按往来分配结算 |
| POST                 | `/ledgers/:id/settlements/:settlementId/reversal` | 撤销误记的结算                     |
| GET                  | `/ledgers/:id/statistics`                         | 日/月/季度/年统计                  |
| GET                  | `/ledgers/:id/events`                             | 日期范围内分页事件明细             |
| GET                  | `/ledgers/:id/history`                            | 最近 100 条审计                    |
| POST                 | `/ledgers/:id/statistics/rebuild`                 | 重建账本统计投影                   |

统计参数：`period=day&value=2026-10-05`、`period=month&value=2026-10`、`period=quarter&value=2026-Q4`、`period=year&value=2026`。未传时默认当月。统计序列补齐期间所有日期，年最多 366 行。

往来列表支持 `direction=receivable|payable`、`status=open|settled`、`q`、`counterparty`、`page`、`pageSize`（最大 100）。收支列表支持原有 month/type/q 分页，也支持 start/end 日期范围。旧的无账本归属 `/bills`、`/categories` 已从生产 API 关闭，不能用于绕过鉴权。

## 原有数据与验证

`pnpm db:init` 执行完整首次初始化，关闭 synchronize。账本表及系统分类种子由记账应用自己的 `server/src/schema.ts` 提供；不再创建无主的“原有账本”，也不回填历史账单。`pnpm user:init` 仅在尚无普通用户时创建初始普通账号及个人账本，凭据保存到 `api/.secrets/bootstrap-user.txt`；已有用户时不修改。旧开发库请使用新库，见 [数据库初始化](database-initialization.md)。

`pnpm test:ledgers` 验证真实 MySQL 下的鉴权、共享、锁定、幂等、各周期余额、历史修正、投影重建、WebSocket revision/撤销通知和并发超额结算。`test:categories` 验证分类跨账本隔离及复合外键。`test:consent` 使用本地 Fake Provider 验证 AI 往来确认、拒绝不写入、伪造回执拒绝与工具去重。`test:chat` 使用隔离的临时用户、数据库记录和测试 Provider验证真实 WebSocket 工具循环，测试后删除各自创建的数据。后台配置测试使用本地假服务商，不请求付费模型。

### 选择与统计界面

App 的日期、月份、季度、年份和选项选择复用自绘底部 Sheet；表单内打开选择器不会提交表单，取消不会改变原值。往来发生日期和收还款日期禁止未来日期，到期日从发生日期起可选并可清除。

统计保留无记录日期，年视图按月汇总，季度视图每 7 天汇总。趋势柱可查看对应期间的原始事件明细。收入和支出分类占比分开；类别超过 6 项时合并其余类别并保留准确金额与笔数。汇总用整数分计算，浮点数只用于图形比例。往来账本所选期间没有普通收支时，展示资金流汇总和趋势，隐藏空白分类图。资金流、期初/期末往来余额和当前剩余应收应付仍分别展示，避免将借还本金计入普通收支。

共享设置按账本信息、成员与共享、安全分组；改名、邀请、权限和密码操作从对应入口打开 Sheet。归档、转让、移除成员和关闭密码仍需要确认。邀请不会携带账本密码，密码授权有效期为 10 分钟。
