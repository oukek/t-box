# 会话 Markdown 预览

回复、思考摘要、分析、提示及工具说明使用同一个前端预览组件。用户输入保持纯文本。Socket 协议与数据库仍保存原始 Markdown 文本，前端不持久化生成的 HTML，不改变时间线顺序和完成后自动折叠的规则。

- `app/src/core/markdown.ts`：独立 Marked 实例、链接协议校验与 DOMPurify 清理。支持标题、列表、任务列表、引用、表格、行内代码和围栏代码；HTML 标签按文本显示，不执行模型返回的 HTML。当前不包含数学公式或语法高亮扩展。
- `app/src/components/MarkdownPreview.vue`：共用预览与代码复制，表格和代码块各自横向滚动。组件及解析依赖通过 `markdown-preview.ts` 按需加载。
- `StreamText.vue`：先按已有打字机节奏更新展示文本，再解析当前文本，因此没有闭合的代码围栏也能预览。历史记录直接展示完整内容，流结束后的剩余打字继续追赶。
- 预览在内容或图片高度改变后通知聊天页。聊天页只在用户保持跟随底部时滚动；上翻查看历史不会被强制拉回。

`pnpm --filter @t-box/app test:markdown` 验证 GFM 格式、每个流式前缀、恶意 HTML／链接协议过滤和稳定输出。`pnpm test:ui-components` 包含该测试及时间线顺序测试。浏览器验证覆盖代码未闭合时的实时显示、完成后收起、重新展开、移动端宽代码滚动和复制。
