# 桌面签名更新验收

2026-11-25，真实 Apple Silicon Mac。两个独立构建的 macOS 安装包使用 ad-hoc Apple 签名，界面和核心分别使用临时测试密钥签名。安装、重启和截图均发生在本机独立的验收应用中。测试服务仅监听回环地址。

| 界面或操作 | 实际结果 |
| --- | --- |
| [仅界面更新提示](01-offer.png) | 当前界面 1.1.16，目标 1.1.17，可选稍后或更新并刷新。 |
| [下载中](02-download.png) | 显示下载进度，隐藏关闭和底部操作。下载时向旧进程发送 Esc 和 Cmd+W 后，原窗口继续显示进度。 |
| [界面签名错误](03-signature-error.png) | 用另一份制品的签名测试，拒绝启用，原进程继续运行，可重试或返回。 |
| [联合更新提示](04-combined.png) | 一次确认，同时准备界面 1.1.17 和核心 1.0.1。 |
| [联合更新后自动打开](05-restarted.png) | 系统重启了方舟进程，出现一个新版主窗口，设置显示两个实际版本。 |
| [启动失败恢复](06-recovered.png) | 提供一份签名正确、没有启动脚本的 1.1.18 界面，握手超时后自动恢复可用的 1.1.17，核心仍为 1.0.1。 |
| [仅界面更新完成](07-ui-only.png) | 进程号保持一致，窗口重载；界面 1.1.17、核心 1.0.0。 |
| [仅核心更新完成](08-core-only.png) | 进程号改变，新窗口自动出现；界面 1.1.16、核心 1.0.1。 |
| [核心签名错误](09-core-signature.png) | 原进程和原版本保留，换回正确签名后通过同一弹窗重试成功。 |
| [下载中断](10-interrupted.png) | 服务端在发送部分界面包后关闭连接，窗口提示重试或返回，已安装版本可继续使用。 |
| [恢复安装包内置界面](11-bundled-fallback.png) | 在没有历史界面包的新安装上测试同一启动故障，原进程自动重新加载内置界面 1.1.16。 |
