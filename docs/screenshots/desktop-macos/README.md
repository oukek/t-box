# macOS 客户端验收

2026-11-25，Apple Silicon，真实 Tauri 窗口。测试服务提供独立账号、空待办列表和待办的两个构建版本。

1. 在首次下载完成后，让测试服务拒绝业务接口和制品请求，再退出并重新启动客户端。[方舟桌面](home.png)
2. 打开已下载的待办 1.1.1。本地页面与导航正常加载，列表显示需要联网读取。[待办离线状态](todo-offline.png)
3. 恢复接口并将测试账号的安装版本更新为 1.1.2。再次打开后，新版页面从新的本地制品目录加载，SDK 完成连接并读到空列表。[新版待办](todo-updated.png)
4. 打开「设置 → 系统版本」，核对同一验收安装包的界面 1.1.16 和桌面核心 1.0.0。[系统版本弹窗](version.png)
