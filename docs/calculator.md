# 数学计算器应用

应用 ID 为 `calculator`，从应用页打开，或在首页用 `@计算器` 接入已配置的 AI。页面不依赖模型或网络来计算，计算本身不扣 AI 额度；从 AI 会话调用工具时，会话模型的 token 仍按平台计费规则计算。

## 功能

16 个入口：基础计算、科学计算、精确分数、数据统计、进制转换、一元二次方程、二元一次方程、矩阵、向量、复数、排列组合、等差/等比数列、几何、多项式、整数与数论、二项分布。

科学计算使用受限语法解析器，支持四则运算、括号、右结合乘方、百分比、阶乘、常量 π/e/ANS、三角/反三角与双曲函数、对数、绝对值、取整、最大最小值、排列组合和公约数/公倍数。DEG 表示角度，RAD 表示弧度。百分号只表示除以 100，没有商用计算器“自动加价百分比”的特殊语义。`-2^2 = -4`、`2^3^2 = 512`。函数使用括号，例如 `sin(30)`、`ncr(20,5)`。`mod` 为余数运算，负数结果遵循被除数符号。

分数、进制和排列组合使用 BigInt 精确运算；其他功能使用有限实数浮点计算，通常展示 15 位有效数字。复数通过单独工具进行四则运算，科学表达式不支持复数或符号求解。多项式导数为指定点的导数值，积分为解析原函数在上下限的数值差；不是通用符号代数系统。

矩阵最多 6×6；数字统计最多 1000 项；排列组合 n≤1000；数论整数≤10¹²；二项分布 n≤10000。各模块检测除零、无定义、数值溢出、尺寸错误和近奇异情况。表达式最多 2000 字符、512 token、64 层原子嵌套。没有 eval、Function、对象属性查找或脚本执行。

## 结构与接入

- `apps/calculator/contracts/src/`：应用自身的可移植纯计算领域模块，按表达式、代数、矩阵、离散数学和分析拆分。`catalog.ts` 声明字段与说明，`calculate.ts` 统一验证和调度，前后端共用同一公式实现。
- `apps/calculator/web/src/`：按键界面、通用表单和账号隔离的本机历史。手机使用 Sheet 选择类型及下拉选项，PC 使用分类导航。最近 20 条历史存于本机，不同步服务器，支持恢复参数和复制结果，清空需要确认。
- `apps/calculator/server/src/`：服务错误适配、受身份认证的 REST 接口、应用工具/技能/专业 Agent 与导航声明。仅依赖应用 SDK 和计算模块，不依赖 AI 运行层。
- 前后端只在各自 application registry 组装计算器；AI 核心无计算业务分支。能力页面自动展示实际 16 个 `calculator_*` 工具、`calculation` 技能与数学助手 Agent。

REST：`GET /api/v1/calculator/types`、`POST /api/v1/calculator/calculations`，均要求登录。后者请求为 `{ "kind": "scientific", "values": { "expression": "sin(30) + 2^3", "angle": "deg", "ans": "0" } }`，结果含类型、标题、结果项与口径说明。没有保存账单等副作用。

工具参数 schema 从目录生成，strict 模式要求列出所有字段；不适用的条件字段可传 null，其他字段必须填写。后端重新执行字段、范围和数学定义域校验。导航仅允许 `kind` 与 `expression`；公式仅用于基础/科学模式，填入后由用户查看或计算，不运行外部代码。

新增数学功能：增加领域函数、目录字段、统一计算调度和边界/数值验证用例。前端表单、后端工具与能力目录会由声明生成，无需修改 AI 核心。
