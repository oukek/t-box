# 配置中心与 Redis

后台 `#/configuration` 仅管理平台 AI 指导 Prompt、会话标题、事实摘要、请求参数、输入长度、执行窗口、轮次、委派、核对、重试、等待时限、缓存 TTL，以及平台图片模型的输出尺寸和请求时限。应用业务设置、Agent/Skill 指导、工具说明和参数契约不在平台后台配置。

四段阶段 Prompt、服务商、模型用途与接口、上下文策略、价格、微信支付、充值优惠、客服和节假日继续使用各自专用页面与原数据库表，不建立第二份配置来源。已有业务专用页面不迁入 AI 配置中心，不将所有领域强行塞入一个无约束 JSON。

## 存储与生效

- `platform_configurations` 保存已注册的定义、默认值和当前值；`platform_configuration_history` 保存发布者、时间、说明和不可变历史；`platform_configuration_state` 保存全局和 AI 配置的版本指针。
- 平台 AI 配置注册把默认值首次入库，后续启动更新定义但不覆盖管理员当前值；重复注册相同定义不增加版本。未注册键不可写入。
- 后台按数据类型、范围、枚举和文本长度校验。写入使用数据库事务及期望 revision；并发修改返回 409。恢复历史值会发布新版本，不改写历史记录。
- 任务 checkpoint 保存平台 AI 执行配置快照；继续任务复用原快照。旧任务无快照时首次恢复补入现行配置，既有工具日志和权限检查不变。图片模型参数随独立图片模型请求读取，其生效方式明确标为“下一次请求”。
- 四阶段 Prompt 保留自己的历史版本与快照。模型仍按既有 configurationKey 检查恢复兼容性，不能用修改 Prompt 绕过模型或应用版本检查。
- 标题不扣用户余额。摘要、模型失败重试仍按真实请求和用量审计；重试预算最大 5，不重跑应用副作用。图片操作结果不确定时仍须核对。

## Redis 一致性

生产使用部署连接信息指定的 Redis（本地配置的 DB 5）；键包含配置类别和数据库版本/不可变支付配置 ID 的摘要。默认 TTL 300 秒，可在配置中心设为 30–3600 秒。Redis 不保存解密后的 API Key、微信私钥、API v3 Key 或 AppSecret，仅缓存加密记录或非密配置。缓存不能替代管理员认证。

读取先从 MySQL 获取轻量的当前版本指针，再读取对应 Redis 值。这里刻意保留一次小查询：即使修改配置时 Redis 不可用、多个 API 实例并存、旧请求晚到，也不能返回旧价格或旧服务商配置。缓存主要省去内容读取、关联查询和转换，不承诺配置读取完全没有 SQL。

写入 MySQL 成功即切换版本；不通过“删 key 后异步重新填充”保证一致性。旧版本键自然过期，迟到回填只能写旧版本。Redis 连接失败、操作超过 150 毫秒或 JSON 损坏时读取 MySQL；缓存故障不阻止配置发布。数据库不可用时不使用可能过期的缓存继续鉴权或收费。

已接入：平台配置、模型运行选择/服务商加密凭据/价格/上下文、四阶段 Prompt、公开费率、微信配置、充值、客服以及节假日同步开关。管理列表为便于编辑可以直接读库；余额、支付结果、权限、账单和用户资料是业务状态，不作为系统配置缓存。

## 应用边界

应用在自身发布版本中提供 Agent、Skill、工具描述、参数 schema 和实现。平台按既有安装授权与版本检查发现、调度这些能力，不从数据库覆盖应用契约，也不自动生成应用后台配置项。

应用 SDK 不提供平台配置声明或平台配置读取字段，工具上下文不传入平台 AI 配置。应用业务设置由应用自身存储和管理；应用升级由发布版本维护。运行层 `configurationSnapshot` 仅供平台 AI 使用，不直接暴露给 SDK。

首次初始化基线不注册 `apps.*` 平台配置。旧任务快照中的同名键不参与应用指导或工具描述；历史配置也不能通过配置接口读取或恢复。配置存储拒绝注册 `apps.*`，应用升级不会添加这些配置，应用业务数据不归配置中心管理。旧开发库按 [数据库初始化](database-initialization.md) 使用新库，不再执行已移除的历史清理迁移。

工具处理器、参数 schema、权限集合、支付验签、幂等校验和阶段协议仍是受版本控制的代码。数据库/Redis 连接、监听地址、基础 CORS 与加密根密钥留在部署配置；它们必须在读取配置数据库之前可用，不能迁入其依赖的数据库。

## 接口与验证

- GET `/api/v1/admin/configuration`：定义、默认值、当前值与发布版本。
- PATCH `/api/v1/admin/configuration/:key`：`{revision,value,note?}`；或 `{revision,restoreRevision,note?}` 恢复历史。不能同时提交 value 与 restoreRevision。
- GET `/api/v1/admin/configuration/:key/history`：最近 50 条发布历史。
- 接口沿用管理员认证、CSRF、禁缓存响应和敏感字段不回显的约束。
- `runtime.configuration` Socket 事件仅公开消息长度限制；Prompt、模型和执行策略不发给客户前端。
- `pnpm --filter @t-box/api test:configuration` 使用真实 MySQL/Redis 和临时配置键，验证跨实例更新、旧请求回填隔离、发布冲突、恢复版本、快照保留、Redis 故障回退和管理接口权限。不会请求真实模型。

首次部署先运行 `pnpm db:init`，再启动 API；同一初始化基线重复运行不覆盖现有配置；旧开发库按 [数据库初始化](database-initialization.md) 处理。注册发生在 API ready 阶段。
