# 记账应用

账本业务、界面、接口、AI 技能及数据库迁移均在 `apps/ledger`，平台仅提供登录、资源存储、应用安装状态和工具执行协议。应用的业务规则不进入 AI 编排核心或平台配置。

## 功能入口

打开账本后的「管理」提供批量记录、分类、账户、预算、周期账单、模板、往来对象与账龄、报销、导入导出、回收站、账本提醒。记录列表提供高级筛选、多选调整分类，点击记录打开详情、复制记账、退款、报销、附件和操作记录。管理表单使用 95vh sheet，底部操作固定。

## 金额与统计口径

- API 使用十进制字符串，计算使用 bigint 分。普通收支、资金流和往来余额分别统计。
- 退款关联原支出，报销到账关联申请，都在实际到账日期抵减净支出并增加资金流入，不计作普通收入。跨期到账可能产生负净支出；统计显示原始支出、退款和报销到账，趋势图支持负值，饼图明确排除负净额并列出这些分类。
- 报销申请增加应收，部分或分次到账减少应收；退款与未取消的报销申请合计不超过原支出。到账支持撤销，申请未到账或全部到账记录撤销后可取消。
- 借还本金只影响现金和应收应付。减免、核销只减少往来余额，独立记录 `adjusted`，不会伪装成收款；撤销会恢复余额。
- 账户期初和余额核对不产生收入支出。内部转账生成等额反向账户流水，不重复计入账本现金流。归档账户不再接受新记录，纠错和恢复仍可修正历史流水。
- 原始财务事件保留，修改、删除、撤销追加修正事件。日统计、分类统计与记录在同一事务更新，可从事件重建。回收站恢复同时恢复统计及账户流水。

## 原子批量与 AI

`POST /api/v1/ledgers/:id/batch` 接收 `items`，每批 1–100 条：

```json
{
  "items": [
    {
      "kind": "debt",
      "ref": "loan",
      "input": {
        "direction": "receivable",
        "counterparty": "张三",
        "amount": "100.00",
        "date": "2026-10-10",
        "dueDate": null,
        "note": "借出",
        "cashMovement": true
      }
    },
    {
      "kind": "settlement",
      "input": {
        "date": "2026-10-10",
        "note": "部分还款",
        "allocations": [{ "debtId": "ref:loan", "amount": "20.00" }]
      }
    }
  ]
}
```

类型：`bill`、`debt`、`settlement`、`refund`、`transfer`。`ref` 为批内唯一英文标识，仅能引用前序同类型记录。所有子操作共享账本锁与 TypeORM 的 READ COMMITTED 写入事务（获得锁后读取最新状态，避免旧快照导致超额），任意一条失败，账单、账户、统计、审计和幂等记录全部回滚。`Idempotency-Key` 必填；同内容同键返回原结果，不同内容同键返回 409。

AI 暴露 `ledger_batch_create`，以及账户查询、预算、退款、转账、周期账单、模板、往来对象、账龄、报销、导入预览和提交工具。写入通过应用确认协议；批量确认展示整批明细，没有只展示前几条的截断。密码由应用授权流程处理，不交给模型。照片和文件由已有资源/AI 能力提取，先转为导入草稿，再校对确认入账，不使用正则猜测用户语义。

## 权限与周期执行

所有接口检查登录、应用安装、账本成员角色与密码授权。账本管理员管理分类、预算、账户和往来调整；编辑成员只能纠正自己创建的记录。共享附件经账本读权限验证，移除附件只移除关联，不删除上传者的原资源。

周期账单默认到期提醒，用户明确开启后才自动登记，**不执行真实付款**。后端每分钟扫描，服务恢复后补处理漏掉的周期；每轮最多 25 个发生日，唯一的规则/发生日保证重复扫描不重复生成。月末按原始锚点计算（1 月 31 日 → 2 月末 → 3 月 31 日），年度按闰日处理。密码变更、角色撤销、创建人停用、应用卸载、账本归档会暂停；重新开启需要有效写入授权。规则错误显示在页面。

预算 80%/用完提醒按月和阈值去重，往来到期/逾期提醒按日去重。目前是**账本内提醒**，不等同于系统推送、短信或后台通知权限。

## 导入导出

UTF-8 CSV 支持字段映射、引号、逗号和多行备注。单次 1 MiB、最多 100 条；预览草稿 24 小时有效，按用户隔离，可校对单行、排除错误或重复行。提交再次查重并原子写入，允许重复需显式确认，重复提交已完成草稿返回原结果。

导出单次最多 10000 条，含收支、往来、收还款分配、退款、报销到账、完整财务事件、账户流水；支持日期范围，收支额外支持分类/类型/记录人筛选。导出文本对电子表格公式前缀转义。所有财务记录的附件沿用平台资源存储，支持多张图片和任意类型文件，单文件 10 MiB，每笔最多 20 个。

`server/src/features`：分类、账户、退款/报销、计划、往来、批量、导入导出、后台调度、应用工具及确认文案，按领域拆分。

`web/src/features`：懒加载管理面板、详情与统一长表单组件。

## 统一记录附件

`ledger_attachments` 用 `subject_kind + subject_id` 关联收支、往来、收还款、退款、转账、报销申请、报销到账、减免核销及账户流水。迁移 `LedgerRecordAttachments1791244831000` 保留旧账单附件，默认迁移为 `bill`。撤销保留凭证；账单进入回收站后附件不可读取，恢复后可继续查看。

先 `POST /api/v1/ledgers/:id/attachment-resources` 上传到当前用户资源（支持任意文件内容，未知类型保存为 `application/octet-stream`），再在创建/修改输入传 `attachmentResourceIds`。资源归属、数量、大小和附件关联在财务事务内验证，附件错误会回滚整个记账或批次，幂等重试不会重复关联。取消表单只放弃关联，原文件仍在上传者的「我的资源」。

已有记录使用 `GET/POST /records/:kind/:record/attachments` 和 `DELETE /records/:kind/:record/attachments/:attachment`；`GET /attachments/:attachment/content` 始终验证账本成员、密码与记录存在状态，不能凭资源 ID 读取其他账本文件。编辑成员只可修改自己记录的附件。移除关联保留原资源，不影响另一笔引用同一文件的记录。

前端复用 `AttachmentPicker`、`RecordAttachments`、`AttachmentButton`，文件输入不设置类型白名单并支持多选，已确认的 PNG/JPEG/WebP 可点击大图；其余类型作为下载文件提供，不在页面执行。AI 提供 `ledger_attachments_list` / `ledger_attachments_add`，以及混合批量的每笔附件字段，关联前展示用户确认；模型只处理资源 ID，不接收密码或上传内容。

## 系统分类与自定义分类

系统分类由记账应用的 `categories/administration` 维护，管理后台的“记账分类”页面调用 `/api/v1/admin/ledger/category-presets`，沿用管理员认证与 CSRF 校验。域逻辑、数据迁移和注册接口均位于 ledger/server，不进入 AI 配置中心。

- 全局 `ledger_category_presets` 保存名称、图标、类型、启用状态、排序和乐观锁版本，`ledger_category_preset_audit` 保留管理员修改前后记录。收支类型创建后不可修改，只能停用，不提供删除接口。
- 账本分类以 `preset_id` 关联预置分类，原分类 ID 保持不变。后台修改及现有账本同步在同一事务完成，账本 revision 随之增加；新账本从数据库复制分类，不再运行时读取写死模板。目录锁和账本锁按统一顺序获取，避免新建账本漏同步。
- 用户只能编辑、停用、删除或合并自定义分类，后端对系统分类同样强制只读。允许自定义分类合并到同类型且启用的系统分类，禁止反向合并。系统分类与自定义分类具有独立名称空间，避免后台改名覆盖用户分类。
- 迁移匹配现有预置分类并保留历史关联；曾被用户改名的预置分类保留为自定义分类，补齐标准系统分类。
- 当前同步适用于现有规模；若账本规模很大，需要版本化目录和异步投影发布机制，不能直接让同步事务无限扩大。

验证：`pnpm test:category-presets` 使用真实 MySQL 的回滚事务验证同步、版本冲突、历史 ID 保留、新账本继承和审计；`pnpm test:ledger-features` 验证用户侧只读限制及自定义分类合并。

## 自定义分类弹窗与图片图标

`web/src/categories/CategoryDialog.vue` 由“记一笔”和分类管理共同复用，提供新增、编辑、默认图标网格以及图片预览。图片选择时仅本地处理，提交时才上传；创建后记账表单自动选中新分类，原金额、备注、日期继续保留。

图片转换为 96×96 PNG 缩略图，后端仅接收 128×128 以内且不超过 64 KB 的 PNG，存入记账应用自己的 `ledger_category_icons`。`bill_categories.icon_id` 关联图片，`icon` 保留默认图标作为加载失败时的回退。分类接口使用 `iconId`（nullable），设为 null 可切回默认图标。上传与创建/编辑均沿用账本权限和持久幂等操作键。选择图片后取消弹窗不会上传。

`POST /ledgers/:id/category-icons` 上传缩略图，`GET /ledgers/:id/category-icons/:iconId` 在账本权限校验后返回图片内容；只允许上传者或已关联此图标的账本成员访问，不开放公共文件链接。绑定图标时校验账本归属；共享编辑可保留已有图片。每个账本最多保留 2000 张缩略图，失败提交后重试复用已上传的 ID。

`CategoryIcon.vue` 在分类选择、分类管理与账单列表统一展示图片，并对读取失败回退默认图标。弹窗监听 visualViewport 适配移动键盘，内容滚动、底部操作固定；文件框 cancel 事件继续由通用 Modal 正确过滤。
