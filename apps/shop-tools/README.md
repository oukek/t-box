# 跨境运营助手

方舟用户应用 `shop-tools`，依据 shop-tools 原项目功能与视觉重新实现；使用方舟公开 SDK、UI、身份与应用安装机制。

## 数据归属

- `shop_tools_workspaces`：账号对应的应用 subject、安装代次、工作表设置、默认参数、站点/物流启用配置、最近计算与方案比较快照、修订号。
- `shop_tools_products`：各工作表的商品行、SKU、名称、成本、重量、目标值、独立费率和行顺序。按 subject / sheet_id / id 普通主键关联，有顺序索引，没有外键。
- `shop_tools_operations`：安装操作与保存请求的幂等回执。

商品、配置和最近结果直接读写 MySQL，不使用浏览器 localStorage、IndexedDB 或 SDK storage，也不包含本地旧数据迁移。页面中的待保存编辑只保留在内存；保存失败明确显示，不能把断网编辑当作已保存。汇率与官方物流响应只在页面会话内保留，Wise 请求有服务端10分钟缓存。

保存采用800ms防抖，只提交修改的行和设置；大批量导入按请求字节数与行数拆批，每批在事务内提交。修订号防止多个设备覆盖，发生冲突后停止自动保存，允许导出本页数据备份后重新加载云端。未知写入结果重试复用原幂等标识。卸载撤销访问但保留业务数据，再安装使用原账号读取；后端同时校验 subject、安装代次和发布版本。

## 功能与分层

- `contracts`：应用清单、工作区与商品类型、SDK操作协议、错误目录。
- `core`：三种定价模式、汇损、运费、区域粘贴、工作簿与保存参数校验、变更比较。
- `server`：应用业务表与事务、数据隔离、分页、保存回执；Wise汇率、Shopee站点/按日期物流/更新记录。
- `web`：商品工作簿、分站点方案比较、结果明细、汇率卡片、配置弹窗；Excel模板、预览追加导入和快照导出。
- `shell`：方舟桌面与独立Web容器注册，可安装、更新、卸载，不默认安装。

每表最多1000行，最多20表，导入文件最大10MB；公式输入不导入。Excel结果为快照，修改输入后导回网页重算。历史日期仅还原物流规则，不还原佣金或汇率。印尼固定交易费沿用原项目每单3000 IDR，未核验现行政策。

## 开发、验证与部署

```sh
pnpm install
pnpm dev
pnpm test:shop-tools
pnpm test:shop-tools:integration
pnpm --filter @t-box/shop-tools-web typecheck
pnpm check:apps
pnpm pack:application shop-tools
```

MySQL集成测试使用当前连接配置创建随机命名、受保护的临时测试库，结束后只删除该测试库，不修改个人业务数据库。

业务表通过 `2026-11-15.shop-tools-workspaces` 增量扩展接入平台 applications schema，保持已发布初始化基线及指纹不变。首次或升级部署需执行方舟既有 `pnpm db:init` / 后端PM2部署初始化流程，扩展可重复运行。没有本地数据迁移或数据库外键。

发布顺序：部署后端并应用建表扩展 → 更新主前端 →「子应用发布（OSS）」选择「跨境运营助手 (shop-tools)」→ 后台上架。新增读写接口权限已登记；发布包位于 `output/application-releases/shop-tools/1.0.0/`，版本以contracts清单为准。当前未执行线上部署。

## 表格与移动端布局

应用基础字号13px，表格输入12px；手机采用紧凑列宽和行高，次要操作、保存/重载、Excel与说明集中在顶部「••• / 更多」操作面板。输入框焦点使用内描边，横向滚动后聚焦会避开固定序号列。

网页整页缩放禁用；表格区域支持双指缩放及触控板Ctrl滚轮，范围60%–180%，底部 − / 百分比 / ＋ 可缩放或重置。缩放只影响表格内容，单指保持原生滚动，导航和弹窗不随表格缩放。缩放比例只在当前视图内保留，不写入本地缓存。

浏览器触摸验证覆盖表格缩放、单指横向滚动、表格外禁止整页缩放、首列焦点、390px手机与1280px桌面布局，以及操作面板中的各功能入口；未做原生真机验证。
