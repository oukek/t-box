# 宝宝日记

独立的用户应用，版本 1.2.2。通过应用市场安装、更新、卸载；不会默认安装。Web、Android、iOS 使用同一份隔离 Web 应用和宿主 SDK。卸载应用保留宝宝档案与成员关系，重新安装后恢复当前账号的访问权限。

## 本版功能

- 成长与创意为主要入口，默认进入成长页；照护统计并入照护内页。照护 tab 默认在 2 岁前显示，未填生日或满 2 岁后收至宝宝档案菜单，历史记录与权限不变；可手动选择始终显示或收起。偏好经 SDK 按账号、应用和宝宝隔离保存在本机，不改家人的导航。界面使用细边框与分隔线，不使用卡片投影。
- 日常照护：快速记录瓶喂、亲喂、睡眠、尿布。亲喂支持分段、左右换边、暂停/继续及混合瓶喂；睡眠支持开始、结束和补记，重开页面根据原始时间恢复时长。
- 逐日/最近 7 天/30 天统计：已记录瓶喂量、奶类、未知奶量次数、亲喂有效时长、睡眠时长与尿布次数；跨日按档案时区分摊，夏令时按真实日界线计算，重叠睡眠不重复累计。原始事件实时计算，不维护容易失真的增量计数器。
- 家人共享计时：同宝宝同类仅一条进行中记录；授权记录者可接手活动计时，已完成记录保持作者/管理者修改限制。新 `care` 范围不会自动授予已有普通成员；由管理者在共享页开启。
- 离线照护草稿：使用 SDK 按账号/应用隔离的本机存储，最多 30 项队列、约 60 KB/宝宝。每条命令保留稳定幂等键，恢复网络或打开应用时补传；冲突/权限变化暂停并显示具体原因，不覆盖云端事实。仅缓存最近至多 80 条文字照护数据，截断时不假装统计完整；不永久缓存私有图片。离线不会绕过后端重新鉴权。未登录仍不能访问宝宝档案。
- 多宝宝档案：昵称、生日、性别、记录时区；归档/恢复、所有权转让。
- 每档案三套主题：暖粉、浅蓝、中性绿。默认跟随性别自动选择（女宝/男宝/未填写），也可手动固定。所有者/管理者保存后，授权成员共享同一主题；编辑实时预览，取消恢复。偏好入库为可空 `theme`：NULL 表示自动，不按访问者或设备分别猜测。老客户端省略此字段时保留已选主题。
- 日记、里程碑、身长/身高、体重、头围；搜索、日期筛选、游标分页、乐观并发版本、回收站。
- 每条记录可附最多 20 个照片/任意类型文件；单文件 10 MB，每宝宝总计 2 GB / 5000 文件（包括预览存储）。
- 成长图表连接真实测量点，支持身高、体重、头围切换，不插值、不使用未经校验的生长标准或健康诊断。
- 创意项目：每天一张、每月留影、玩偶参照、小手小脚、第一次、画作；排序、日期、说明、位置/缩放/旋转对齐、上一帧叠加参考。
- 本地动画：切换、淡化、滑动、缩放；每张 0.04–10 秒、0.25–8 倍速、循环/倒放、画面比例、日期/月龄文字、日期范围。
- 按宝宝共享：所有者、管理者、记录者、查看者；普通成员分别授权日记/成长/创意/日常照护内容与原图/文件下载。记录者只能改自己的记录。仅管理者内容的可见范围创建后固定，不能通过改记录绕过附件权限。
- 邀请码有限期、次数、撤销、并发使用控制；只存邀请码摘要，原码仅在创建结果中展示。
- 照护 AI 工具：`baby-care` 按需提供查询/统计、批量记录、版本化更新/计时；全部在应用后端运行，纯计算在 core 复用，不往 AI runner 添加业务代码。
- AI 服务端工具：查询档案、查询记录、原子批量添加 1–30 条多类型记录、查询成长测量、查询创意项目。工具随应用按需发现，成员管理和转让不开放给 AI。

吸奶/储奶、辅食、健康用药、提醒调度、疫苗计划、WHO 百分位、服务端视频导出不包含在本版。当前创意功能是设备内播放，不产生 MP4/GIF 文件。

## 分层

- `contracts`：清单、图标、DTO、严格参数校验、稳定错误码。
- `core`：纯月龄、测量序列、播放位置与照片对齐计算，前后端共用。
- `server`：应用自己的 TypeORM 实体、表定义、事务、角色/范围权限、写入幂等、AI 工具和安装生命周期。
- `web`：紧凑手账界面；只经 SDK 调宿主；不读取宿主 Token、全局资源或 AI 历史。
- `shell`：导航适配，无宝宝业务代码。

宿主只增加通用 `files.private` SDK 端口与私有存储服务；权限由应用注册的 `PrivateMediaPolicy` 决定。AI runner 内无宝宝业务分支。工具执行经过安装版本/代次、权限、幂等与应用接口。会话记录携带内容范围的资源引用；权限收回后旧会话也会重新鉴权。

后端写入先锁安装代次，再锁宝宝档案，和对应资源/文件；批量写入整体事务提交。重复调用标识返回已提交结果，权限检查先于幂等结果读取。共享变更与记录变更串行化，版本冲突不会静默覆盖。

主题配色由 Web 的 `theme.css` 维护，默认选择规则为应用契约中的纯函数；AI 与宿主不管理宝宝主题。配色应用到当前 iframe 的根节点，弹层、图表、卡通插画随档案切换；草稿预览只存在内存中。

## 私有文件

本地开发不配置 OSS 时使用 `api/.storage/private`，不映射到静态目录。生产共用现有业务 Bucket（默认 `tboxos`）与服务端 OSS_REGION / OSS_ACCESS_KEY_ID / OSS_ACCESS_KEY_SECRET（可选 OSS_SESSION_TOKEN），无需独立桶或新增环境变量。

原文件与预览各使用独立的 256 位随机对象名，路径为 `uploads/resources/application-files/<64位十六进制名>`，不包含原文件名、资源 ID 或业务 ID。对象 ACL 写为 private，覆盖桶的公共读默认值。服务端读取后经已认证 SDK 返回文件内容，应用拿不到 OSS 对象路径或永久链接。随机命名不是文件内容加密，业务授权、导出权限和对象级权限继续生效。

原文件私有保留；照片另生成去除 EXIF/GPS 的 JPEG 预览。当前运行时不能解码的 HEIC 会明确提示，改用 JPEG/PNG/WebP；不把无法解码内容当成成功图片。未知文件按下载附件处理，HTML/SVG 不在应用中执行。

照片预览仅存在当前页面内存，不写浏览器永久缓存。预览缓存最多 24 张/48 MB，照片按可见区域加载、编辑缩略图只显示当前附近 7 帧，播放器只预读当前/下一帧。关闭应用、切换宝宝、切换账号会清理。上传未绑定记录/项目的草稿在 24 小时后由恢复器清理；已关联文件随记录/项目软删除保留，用于恢复。当前不对保留中的关联附件自动物理清除。

查看授权不能阻止截图或撤回已经下载的文件。原图/文件下载额外检查导出权限。

## 开发、升级和发布

当前采用统一新库初始化，不再提供旧开发库兼容升级。配置新的 `MYSQL_DATABASE` 后执行 `pnpm db:init`，已有数据库保持原样。资源包基线及部署步骤见 [数据库初始化](../../docs/database-initialization.md)。

## 1.2 升级

先按 `docs/database-initialization.md` 初始化新数据库，不转换旧开发库。在管理后台发布 1.2.0 后，由应用市场更新安装，才能获得新增 care 方法权限。仅修改源图标或开发源码不会重写不可变的已发布版本。旧安装的开发页面会显示更新入口。

运行 `pnpm test:baby-care` 可检查纯计算/离线队列和独立临时数据库的照护事务、权限、协作、修改历史；测试会自行创建并删除随机命名的数据库，不改个人业务库。

## 1.2.1 界面更新

本版仅调整导航、个人设备偏好和扁平样式，无数据库变更，照护接口权限不变。已发布的 1.2.0 产物保持不可变；构建并提交 1.2.1 后，在后台手动发布，再由应用市场确认更新。`pnpm apps:submit:local baby-diary` 可准备本地待发布构建。

## 1.2.2 卡片统一

照护的喂奶、睡眠、尿布入口与成长页的写日记、记测量、里程碑共用 `QuickActionCard.vue` 和同一套布局、尺寸、文字及图标底色样式。统计卡片也沿用同一卡片表面，不使用阴影，不再维护照护专用的分隔条布局。本版包含 1.2.1 的导航调整，可直接发布并更新到 1.2.2，无需先发布 1.2.1。
